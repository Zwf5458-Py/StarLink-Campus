# 📱 海星家园共育跨端小程序框架 (starlink-campus-app)

> **基于 Uni-App / Vue 3 + 微信小程序原生架构打造的家园共育与教师移动工作台**

---

## 🌟 核心功能特色

### 👨‍👩‍👧 1. 家长端 (Parent Mode)
- **👦 孩子体温与入园状态卡**：实时同步班牌与晨检体温检测数据（如 36.5℃ 正常状态）。
- **🎫 二维码出入接送卡**：动态生成 `PASS-8890214` 安全接送通行码，供园区闸机和班牌扫码核验。
- **🥗 每日健康食谱与过敏源提示**：实时查看早餐、午餐、午后点心及食物过敏源比对。
- **📝 家长在线请假**：直接线上提交病假、事假申请，自动推送至班主任与 OA 审批系统。

### 👩‍🏫 2. 教师工作台 (Teacher Mode)
- **📊 班级实时考勤汇总**：实时查看 27/28 应到/实到人数与缺勤人次。
- **🩺 体温一键补录**：支持教师在移动端为未接打卡的幼童补录晨检数据。
- **📷 班级圈相册发布**：直接调起微信相机/相册，实时发布照片动态与视频。
- **📍 教职工 GPS 考勤打卡**：园区地理围栏范围内秒级定位打卡。
- **📝 园务 OA 移动审批**：随时随地审批请假、补卡与后勤采购单。
